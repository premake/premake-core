Specifies whether to use stack and buffer protections.

```lua
buffersecuritycheck "value"
```

This is an alias for [hardenstack](hardenstack.md). Use `hardenstack` in new scripts.

### Applies To ###

Project and file configurations.

### Availability ###

Premake 5.0.0-beta8 or later.

### Examples ###

```lua
buffersecuritycheck "On"
```

* [hardenstack](hardenstack.md)
